# Результаты проверки первой версии

**Обновление 10 ноября 2026:** 138 тестов прошли, добавлены календарные кварталы, конструктор диаграмм, удаление показателя, маскот и Word по образцу. Подробности — [в проверке обновления](update-2026-11-10.md). Ниже сохранён протокол первоначального выпуска.

Проверено 9 ноября 2026 года. Основная среда — Linux, Python 3.12, PostgreSQL 17, Docker Compose. Нативные Windows и Microsoft Word в этой среде отсутствуют; инструкции Windows подготовлены для Docker Desktop с Linux-контейнерами.

Стандартный Dockerfile в репозитории сохранён.

## Что ещё требуется

- Согласовать определения и единицы спорных рядов, территорию и полные формулировки финтеста, окончательную методику ИРФК.
- Получить официальные файлы/доступы Росстата и ФНС, выгрузку онлайн-зачёта, точные числители и необходимые социологические базы/срезы.
- Задать серверный ключ OpenAI и проверить реальный API-вызов в разрешённом организацией контуре.
- Выполнить приёмку на Windows/Docker Desktop и визуальный просмотр отчёта в используемой версии Word.
- Разместить сервис на внутреннем сервере организации с доменом, HTTPS, учётными записями и регулярным резервным копированием. Публичный сервер с внутренними данными не разворачивался.
