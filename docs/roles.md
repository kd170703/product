# Пользователи и права

В административной панели **https://ваш-домен/admin/** (локально — **http://localhost:8000/admin/**) администратор создаёт сотрудников и назначает группы «Просмотр», «Редактирование» или «Администрирование». Просмотрщик читает данные и скачивает отчёты; редактор вводит данные, импортирует, создаёт поправки и формирует отчёты; администратор управляет пользователями, справочниками и настройками. Статус персонала для входа в Django admin включайте только тем, кому нужна эта панель. Не используйте учётную запись суперпользователя для повседневной работы.

| Группа | Возможности |
| --- | --- |
| Просмотр | Чтение активных данных, диаграммы, история и скачивание выпущенных отчётов |
| Редактирование | Возможности просмотра, ввод и импорт, паспорта, ручные поправки, удаление показателя из активного реестра, выпуск отчётов |
| Администрирование | Управление пользователями, справочниками и конфигурацией приложения |

Учётная запись без назначенной роли не получает доступ к рабочим данным. Суперпользователь предназначен для настройки и восстановления доступа.

Удаление показателя скрывает его из активных выборок и новых отчётов. Исходные значения, автор удаления и ранее выпущенные документы остаются в истории. Очередной импорт не восстанавливает удалённый показатель.

На сервере перед доступом к данным сотрудник подключает TOTP. Пароль, приложение-аутентификатор и резервные коды описаны в [инструкции безопасности](security.md). ФИО и почту заполняйте только при необходимости; см. [размещение персональных данных](data-localization.md).
