# Выгрузки и панель GPT

## Зафиксированные отчёты

Вкладка отчётов получает тот же отфильтрованный список наблюдений, что и таблица приложения. Экспорт не выполняет независимый запрос к источникам и не пересчитывает неизвестные числители. Word и Excel формируются из одного JSON-снимка, который содержит фильтры, значения, состояния данных, версии наблюдений, ручные поправки (если они применены), сведения об источниках, дату формирования и полные определения версий методик и формул.

Для снимка вычисляется SHA-256. Готовые DOCX и XLSX сохраняются в файловом хранилище приложения; скачивание ранее выпущенного отчёта возвращает готовый файл. Новая загрузка данных создаёт новую версию наблюдения, но не изменяет выпущенный отчёт. Резервная копия должна включать PostgreSQL **и** каталог `media`, содержащий отчёты и исходные публикации.

Структура Word следует 13 тематическим разделам сводной таблицы. Внутри темы данные разделены на социологию, социально-экономические показатели и финтест в порядке исходного отчёта. ИРФК и онлайн-зачёт идут дополнительными блоками. Вместо трёх узких параллельных колонок подробные наблюдения каждого блока размещены последовательно в собственной таблице: это сохраняет тематическую структуру и читабельность длинных вопросов и ссылок. Таблицы редактируемые, без заливки; основной шрифт Times New Roman 14. Прямые официальные ссылки сохраняются как гиперссылки; для загруженного файла указываются имя, лист и ячейка/страница.

Числовой ноль, отсутствие данных и неприменимость различаются в таблицах. В Excel числовая ячейка для отсутствующего/неприменимого значения пуста, а отдельный столбец содержит состояние; числа и даты сохраняются в собственных типах Excel. Разные единицы не складываются. Одна запись может присутствовать под несколькими тематическими рубриками Word, сохраняя один ID и одну версию; лист «Наблюдения» Excel содержит по одной строке на наблюдение.

Данные с конфликтом остаются в редактируемых таблицах с пометкой и перечнем вопросов проверки; в диаграммы они не включаются. Диаграммы объединяют только один показатель, единицу, территорию, тип периода и группу; распределения ответов дополнительно разделены по периоду. Статусы непроверенных наблюдений видимы. В каждом тематическом блоке Word показано не более двух сопоставимых диаграмм; это ограничение явно указано в отчёте. Полный набор отфильтрованных строк остаётся в таблицах Word и на листе «Наблюдения» Excel. Ряды статистики с неподтверждёнными датами или единицами в диаграммы не попадают. Динамика финтеста строится по отдельному вопросу и периоду без сложения округлённых долей.

## GPT: предложение с подтверждением

Настройте на сервере `OPENAI_API_KEY` и `OPENAI_MODEL`. Ключ не передаётся в шаблоны, браузер или выгрузки. Если ключ или модель не настроены, только панель GPT сообщает о необходимости настройки; импорт, ручной ввод и отчёты работают самостоятельно.

Поддерживаются DOCX, XLSX, PDF с текстовым слоем, TXT, CSV, JSON и Markdown. Ограничения: 20 МБ на файл, 80 МБ распакованного Office-документа, 120 000 символов извлечённого текста, 300 предложений в одном ответе. Для сканированного PDF требуется предварительное OCR. Формулы Excel передаются как формулы, не исполняются; процентный формат ячейки отображается кодом приложения.

Приложение отправляет текст документа, инструкцию сотрудника и справочник показателей в OpenAI Responses API со строгой JSON-схемой, без инструментов и без автоматической записи. В запросе задано `store=False`. Документ рассматривается как недоверенный текст. API не получает инструмента исполнения кода и доступа к базе. Секреты сервера в запрос не включаются.

Локальная проверка отклоняет неверные числа, даты, состояния и опасные схемы URL. Несопоставленные коды, несовпадающие единицы, пустые обязательные поля и неоднозначности помечаются для проверки. Предложения всегда имеют статус «Требует проверки»; фактическая запись выполняется после явного подтверждения через обычный импорт приложения с проверкой прав. Арифметика и методические расчёты остаются в программном коде. По округлённым процентам точные количества правильных ответов не восстанавливаются.

## Проверки

`tests/test_exports_gpt.py` содержит проверки структуры и содержимого Word/Excel, различения нуля и пропуска, ссылок, снимков версий, защиты от формул в Excel и локальной валидации GPT. API в тесте заменён заглушкой. Успешный тест заглушки **не означает** проверенный реальный вызов OpenAI. Для живой проверки требуется ключ с доступом к выбранной модели и сети; её результат следует фиксировать отдельно.
