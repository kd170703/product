# Поля About

Подготовлены описание и темы для текущего имени репозитория `product`.

**Description**

Внутренний сервис мониторинга финансовой культуры: показатели, дашборды, автоматические обновления и квартальные отчёты.

**Topics**

`django`, `postgresql`, `docker`, `finance`, `monitoring`, `financial-literacy`

**Website**

Заполняется после появления адреса развёрнутого сервиса. Локальный `localhost` не является публичным адресом проекта.

Чтобы применить поля, владелец репозитория открывает GitHub → About → значок настроек. Текущая интеграция позволяет работать с кодом и workflow, но GitHub вернул HTTP 403 на изменение описания и topics: у интеграции нет административного разрешения.
