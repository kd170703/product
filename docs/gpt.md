# Настройка GPT

GPT выключен по умолчанию: `OPENAI_ENABLED=0`. Сначала организация определяет, какие документы разрешено передавать внешнему API; см. [размещение данных](data-localization.md). Остальные функции сервиса работают без GPT.

## Сервер организации

На сервере запишите ключ в `.secrets/openai_api_key`, сохраняя закрытый доступ к каталогу `.secrets`. Ключ не включается в `.env.prod`. В `.env.prod` задайте `OPENAI_ENABLED=1` и `OPENAI_MODEL` с доступной вашему API-проекту моделью. Примените настройки:

```sh
sh scripts/server.sh up -d --force-recreate web worker
```

## Локальная установка

В локальном `.env` задайте `OPENAI_ENABLED=1`, `OPENAI_API_KEY` и `OPENAI_MODEL`. Затем выполните `docker compose up -d --force-recreate web worker`. Эти файлы не должны попадать в репозиторий.

## Работа с предложениями

Загрузите документ или вставьте текст в панели GPT, добавьте инструкцию и проверьте предложения. Запись подтверждает сотрудник; вычисления выполняет код приложения. Ключ не передаётся в браузер. Поддерживаются DOCX, XLSX, PDF с текстовым слоем и текстовые файлы; сканы требуют предварительного OCR.

Схема извлечения, ограничения документов и правила подтверждения: [выгрузки и GPT](exports-and-gpt.md#gpt-предложение-с-подтверждением). Проверка с заглушкой не подтверждает реальный вызов API; в этой среде рабочий ключ не предоставлен.
