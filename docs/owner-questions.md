# Вопросы владельцу данных и необходимые доступы

Работа приложения, PostgreSQL, импорт, ручные поправки, расписание и выгрузки не требуют ответов на эти вопросы. Они нужны для содержательной проверки отдельных данных и расширения интеграций.

| Вопрос | Почему требуется решение | Поведение первой версии |
|---|---|---|
| Карты: все эмитированные, расчётные или только кредитные? Уточнить также круг владельцев карт. | Название в реестре и фактически выбранная колонка таблицы 6 Банка России расходятся. | Подключение зарегистрировано, автоматическая запись заблокирована до выбора `metric` и `definition_confirmed`; исходные значения доступны с замечаниями. |
| Предоставить доступный официальный XLSX Росстата по среднедушевым доходам Москвы. | Страница и проверенные варианты сервера возвращали HTTP 503. Структура реального файла не подтверждена. | Есть импорт сохранённого файла и явное соответствие ячеек; годовые и квартальные периоды задаются отдельно. |
| Предоставить официальный XLSX формы 5-ДДК по Москве. | Индекс выпусков доступен, но выпуск и файл при прямой загрузке возвращали HTTP 403. Нужно подтвердить строку числа налогоплательщиков, а не суммы вычетов. | Используется тот же загрузчик для локального файла; необходимы проверенные `cells` и `expected_markers`. |
| Согласовать единицы и периоды спорных статистических показателей. | В Excel и Word есть расхождения, включая единицы и остатки на дату против квартальных значений. | Исходные значения сохраняются, неоднозначная дата не подменяется датой загрузки. Полный частный список сверки предоставляется отдельно. |
| Социология: база каждой доли, анкета, признак множественного выбора, возрастные срезы и будущие волны. | Базы и возрастные группы в предоставленном реестре не раскрыты; сумма долей выше 100% может означать вложенные ответы. | Доли показаны как опубликованные, без восстановления численности и нормирования до 100%. Неустановленный множественный выбор хранится как неопределённый. |
| Финтест: точные количества правильных ответов, территория участников и правило сопоставимости окон. | Округлённые проценты не определяют точный числитель. Дополнительное окно Word пересекается с полугодием. | Точная сводная доля не рассчитывается без числителей; пересекающиеся окна и разные версии вопросов не суммируются. |
| Предоставить источник онлайн-зачёта. | В материалах нет согласованной выгрузки. | Раздел показывает отсутствие данных; доступны ручное добавление и импорт. |
| Согласовать финальную методику ИРФК: компоненты, веса, нормирование, периоды, источники. | Документ содержит многочисленные исправления, комментарии и формулы; окончательная редакция не утверждена. | Создана черновая версия методики, полный индекс не публикуется. Расчёт допускает только утверждённые версии и полный проверенный набор компонентов. |
| API OpenAI: ключ, модель и разрешённый состав документов. | Ключа нет в окружении. Реальный запрос не выполнялся. | Панель показывает необходимость настройки. Проверены локальная валидация и вызов с заглушкой; подтверждение импорта обязательно. |
| Внутренний сервер, домен, HTTPS, пользователи и резервное хранилище. | Это организационные доступы, отсутствующие в рабочей среде. | Есть воспроизводимый локальный запуск Compose, роли и инструкции резервирования. Публичный доступ к внутренним данным не включён. |

Ключи API и пароли вводятся в серверный `.env` или систему секретов. Их не нужно пересылать в чат или коммитить в GitHub.
