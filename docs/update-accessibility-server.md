# Читаемость интерфейса и подготовка серверного запуска

Дата проверки: 10 ноября 2026 года. Этот протокол дополняет [проверку первой версии](verification.md) и [предыдущее обновление](update-2026-11-10.md).

## Интерфейс

- Основной текст — 16 px, таблицы — 14 px, минимальные подписи — 12 px. Поля ввода — 16 px, интерактивные элементы — не менее 44 px.
- Цвета сведены в токены; минимальный контраст проверенных текстовых подписей и placeholder превышает 4,5:1.
- SVG строится по фактической ширине контейнера. Подписи диаграмм сохраняют физический размер 14 px при изменении ширины.
- Серии отличаются цветом, маркером и штриховкой. Есть подписи, управление с клавиатуры, заголовок и описание SVG, таблица значений с caption и scope.
- Иконки используют локальный SVG-спрайт. Логотипы WebP весят 6 и 17 КБ, отдельный favicon — 8 КБ. Исходный маскот сохранён в assets и не загружается рабочими страницами.
- Шапка закреплена, повторяющиеся крошки убраны. На телефонах реестр отображает строки карточками с подписями полей. Убраны декоративные точки, похожие на живой статус.
- CSS разделён на base/layout/components/charts; шаблоны отформатированы. Добавлены EditorConfig, Prettier, Stylelint и djlint.
- README сокращён; четыре иллюстрации сняты на синтетических данных. Реальные документы и персональные сведения не публикуются.

## Сервер и безопасность

- Добавлены `compose.prod.yaml`, Caddy и скрипты первоначальной настройки и управления сервером. У приложения и БД нет опубликованных портов; секреты читаются из файлов. Повторная настройка не заменяет ключи.
- GitHub Actions проверяет код, собирает образы приложения и резервирования и публикует их в GHCR по SHA. Перед перемещением `main` предусмотрен запуск изолированного окружения и проверка восстановления. Сервер скачивает образы без сборки.
- Django обновлён до поддерживаемой LTS-версии 5.2.19. Отсутствующий, пустой и известный шаблонный SECRET_KEY останавливает запуск.
- Axes хранит счётчики в PostgreSQL: пять ошибок блокируют логин или адрес на 30 минут. POST/GET и заголовки браузера не сохраняются; журнал маскирует логин и IP. Worker очищает устаревшие записи.
- Реализованы TOTP, локальный QR и десять одноразовых резервных кодов. Для серверной схемы второй фактор обязателен; активированные учётные записи защищены и при локальном запуске. Проверка действует на страницы, API, скачивания и Django admin.
- GPT выключен по умолчанию, одного наличия ключа недостаточно. Размещение персональных данных, журналов и копий в России описано отдельно; фактическую площадку и процессы подтверждает организация.

## Границы проверки и необходимые данные

На реальном сервере организации установка ещё не выполнялась. Нужны серверные доступы, домен/DNS, выбранный способ сертификатов, подтверждённое размещение основной базы и копий в России, ответственные за эксплуатацию и персональные данные. Доступ к частным пакетам GHCR может потребовать входа с правом read:packages.

Реальная выдача и продление TLS-сертификата, работа корпоративной сети, восстановление после потери всего сервера и приёмка в нативных Windows/Microsoft Word требуют инфраструктуры владельца. Проверка подключения OpenAI с настоящим ключом не выполнялась; ограничения Росстата/ФНС и согласование методики ИРФК остаются прежними.

Настройки About и topics репозитория подготовлены в [инструкции владельцу](repository-settings.md), но GitHub отклонил их изменение с HTTP 403: у подключённой интеграции нет административного права на метаданные репозитория. Это не ограничивает публикацию кода и workflow.
